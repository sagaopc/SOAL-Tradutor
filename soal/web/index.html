Traduza os diálogos de Skies of Arcadia Legends

Aponte para a pasta onde a ISO foi extraída. O programa lê todos os diálogos, guarda uma cópia dos arquivos originais e deixa você traduzir sem limite de tamanho por fala.

Projetos recentes
  1. Extraia a ISO. No Dolphin: clique direito no jogo, Propriedades, Sistema de arquivos, clique direito em “Disco”, Extrair disco inteiro.
  2. Abra a pasta aqui. É a pasta que contém files e sys.
  3. Traduza. Tudo é salvo sozinho numa pasta de projeto ao lado da pasta do jogo.
  4. Grave no jogo. Os arquivos traduzidos substituem os da pasta extraída; os originais ficam guardados no projeto.
  5. Teste. No Dolphin, abra o arquivo sys/main.dol da pasta extraída. No recomp (port nativo), basta iniciar o jogo: a tradução é gravada direto no jogo importado.

    Ao importar, as linhas que passam do tamanho da caixa são quebradas de novo automaticamente. Nos menus de escolha, mantenha uma opção por linha.

    Trazer de outro projeto
    Copia as traduções e os nomes de outro projeto do SOAL Tradutor, como o da versão americana para o da europeia. As falas são ligadas pelo arquivo e pela chave, que são os mesmos nas duas versões. Se o texto em inglês for diferente entre elas, a tradução vem marcada para revisar. O que este projeto já tem traduzido não é trocado.

    Ajustes

    A linha mais longa do jogo original tem 48 colunas.
    O original nunca passa de 3.
    Versão europeia: você traduz a partir do inglês, e a tradução é gravada no lugar do idioma escolhido. No jogo, escolha esse idioma no menu. Os outros idiomas ficam como estão; falas ainda não traduzidas aparecem no idioma original desse lugar.
    As 11 páginas do começo do jogo (“In a world shrouded in mystery…”) são imagens. A tradução é desenhada com esta fonte no lugar do texto original.
    A fonte da versão americana não tem acentos. Na primeira opção, cada letra acentuada toma o lugar de um símbolo que os diálogos não usam. Só há 15 lugares; as letras que ficarem de fora são gravadas sem acento.
    Qual símbolo cada letra ocupa
    Só vale para o recomp. Os arquivos traduzidos são completados com zeros até múltiplos de 32 KB, para que o tamanho deles quase nunca mude de uma gravação para a outra. Ainda não foi testado dentro do jogo.
    Tradução automática

    Usada pelos botões “Traduzir automático”. Você escolhe o serviço e decide quais falas traduzir; as falas traduzidas assim ficam marcadas para revisar. A chave fica só neste computador, fora do projeto.

    Onde ficam as traduções

    Tudo o que você traduz fica na pasta do projeto, separada do jogo; o jogo só muda em “Gravar no jogo”. O arquivo que guarda as traduções é o projeto.json.

    Com uma pasta escolhida, o programa guarda uma cópia do projeto.json com data e hora a cada 10 minutos de trabalho e ao fechar, e mantém as 20 mais recentes, além de um projeto.json sempre igual à última. Para voltar uma cópia, feche o programa e coloque o arquivo na pasta do projeto com o nome projeto.json.

    Traduzir automático na ordem da história

    Traduz as falas que faltam, capítulo por capítulo, na ordem em que aparecem no jogo, usando o serviço escolhido em Ajustes (). Falas iguais já traduzidas são reaproveitadas, e as novas ficam marcadas como “tradução automática” para você revisar.

    Pode parar quando quiser: o que já foi traduzido fica salvo, e começar de novo continua das que faltam. Se o serviço parar de responder, a tradução para sozinha e diz o motivo.

    Gerar ISO

    Monta uma imagem de disco de GameCube (.iso) com os arquivos da pasta do jogo, para guardar, jogar no Dolphin ou usar num console. As posições dos arquivos que mudaram de tamanho com a tradução são ajustadas sozinhas. A pasta do jogo não é alterada.

    A imagem ocupa cerca de 1,4 GB. No fim, o programa confere a imagem gerada antes de entregá-la.
