## Downloads

| Arquivo | Para quem |
|---|---|
| **`SOAL-Tradutor-0.5-windows.zip`** | Windows 10 e 11, **sem instalar nada**. Descompacte e abra o `SOAL Tradutor.exe`. |
| `SOAL-Tradutor-0.5.zip` | Qualquer sistema com Python 3.8 ou mais novo. Abra o `SOAL Tradutor.pyw`. |

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o `.exe` não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**. O `.exe` é compilado pelo próprio GitHub a partir do código deste repositório (veja a aba Actions), e a soma SHA-256 de cada arquivo está em `SHA256SUMS.txt`.

## Novidades desde a 0.2

- **Janela própria**: o programa abre na sua própria janela, sem abas e sem console, e encerra salvando o projeto quando a janela é fechada. Usa o motor do Microsoft Edge que já vem no Windows.
- **Versão .exe**: não precisa mais do Python no Windows.
- **Tradução automática opcional**: botão "Traduzir automático" em cada fala (Alt+T) ou nas falas que faltam no arquivo, com o serviço que você escolher em Ajustes: Ollama ou LM Studio no seu PC, Claude (API da Anthropic), DeepL, Google ou LibreTranslate. Os modelos de linguagem recebem as regras de estilo (adaptar gírias e termos de marujo), o glossário, o gênero de quem fala e a fala anterior. Tudo que vem da máquina fica marcado para revisão.
- **Planilha para traduzir**: "Exportar falas para traduzir" gera uma linha por fala diferente (11.358), com quem fala, a fala anterior e o limite de tamanho. Na importação, as repetições são preenchidas e as linhas longas são quebradas para caber na caixa.
- **Aviso de pasta já modificada**: ao abrir, o programa compara os arquivos com os do disco americano original.
