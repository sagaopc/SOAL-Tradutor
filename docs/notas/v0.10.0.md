## Downloads

| Arquivo | Para quem |
|---|---|
| **`SOAL-Tradutor-0.10.0-windows.zip`** | Windows 10 e 11, **sem instalar nada**. Descompacte e abra o `SOAL Tradutor.exe`. |
| `SOAL-Tradutor-0.10.0.zip` | Qualquer sistema com Python 3.8 ou mais novo e o Pillow (`pip install pillow`, só para a introdução). Abra o `SOAL Tradutor.pyw`. |

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o `.exe` não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**. A soma SHA-256 de cada arquivo está em `SHA256SUMS.txt`.

## Novidades

- **Patch de tradução.** Na janela **Gravar no jogo**, o botão **Patch…** cria um arquivo `.soalpatch` com o seu trabalho e aplica esse arquivo em outro jogo da mesma versão.
  - O patch guarda só as traduções, os nomes de quem fala, os termos, os ajustes e as imagens que você editou. Não leva arquivos do jogo nem o texto original.
  - **Numa ISO**: a original não muda. O programa monta uma ISO nova, já traduzida.
  - **Numa pasta extraída ou num recomp** (a pasta do programa ou a de dados): a tradução é gravada nos arquivos, e o programa cria um projeto próprio para esse jogo, com os originais, que aparece na lista de recentes. No recomp europeu, o idioma do console é ajustado.
  - Falas cujo texto em inglês seja diferente no jogo de destino entram marcadas para revisar.
- A janela de escolher arquivos agora também escolhe arquivos (o patch e a ISO), além de pastas.
