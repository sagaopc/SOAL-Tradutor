## Downloads

| Arquivo | Para quem |
|---|---|
| **`SOAL-Tradutor-0.8.1-windows.zip`** | Windows 10 e 11, **sem instalar nada**. Descompacte e abra o `SOAL Tradutor.exe`. |
| `SOAL-Tradutor-0.8.1.zip` | Qualquer sistema com Python 3.8 ou mais novo e o Pillow (`pip install pillow`, só para a introdução). Abra o `SOAL Tradutor.pyw`. |

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o `.exe` não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**. A soma SHA-256 de cada arquivo está em `SHA256SUMS.txt`.

## Novidade

- **Trocar de jogo**: botão novo na barra de cima, com a versão aberta ("Americana ▾" ou "Europeia ▾"). Ele lista os projetos já abertos para trocar com um clique e tem o campo para abrir outra pasta de jogo, americana ou europeia. Antes, como o programa reabre o último projeto ao iniciar, só dava para chegar na tela inicial por Ajustes → Fechar projeto.

As novidades da 0.8.0 (itens, menus e sistema; introdução; tradução automática dos nomes) estão nas [notas da 0.8.0](https://github.com/sagaopc/SOAL-Tradutor/releases/tag/v0.8.0).
