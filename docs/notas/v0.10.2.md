## Downloads

| Arquivo | Para quem |
|---|---|
| **`SOAL-Tradutor-0.10.2-windows.zip`** | Windows 10 e 11, **sem instalar nada**. Descompacte e abra o `SOAL Tradutor.exe`. |
| `SOAL-Tradutor-0.10.2.zip` | Qualquer sistema com Python 3.8 ou mais novo e o Pillow (`pip install pillow`, só para a introdução). Abra o `SOAL Tradutor.pyw`. |

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o `.exe` não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**. A soma SHA-256 de cada arquivo está em `SHA256SUMS.txt`.

## Correção

- **Versão europeia: as imagens do idioma escolhido.** Com o espanhol (ou o francês, ou o alemão) escolhido em Ajustes, a janela de Imagens agora mostra e edita as imagens desse idioma, que são as que vão para o jogo. Antes ela mostrava as inglesas e levava a edição para o outro idioma; nos menus isso não funciona, porque a disposição das palavras muda de um idioma para outro e o jogo recorta cada palavra do lugar dela (“Foc/us” no inglês, “Enfo/que” no espanhol).
  - O botão **Inglês** (segure), no editor, mostra a imagem inglesa para comparar. A dica de cada imagem traz o texto em inglês.
  - O que já tinha sido editado no inglês foi copiado, uma vez, para a imagem correspondente do idioma, para não se perder. Confira os menus com o botão **Original** e refaça onde a disposição for diferente.
  - No prólogo, a janela mostra só a imagem do idioma escolhido.
