## Downloads

| Arquivo | Para quem |
|---|---|
| **`SOAL-Tradutor-0.9.3-windows.zip`** | Windows 10 e 11, **sem instalar nada**. Descompacte e abra o `SOAL Tradutor.exe`. |
| `SOAL-Tradutor-0.9.3.zip` | Qualquer sistema com Python 3.8 ou mais novo e o Pillow (`pip install pillow`, só para a introdução). Abra o `SOAL Tradutor.pyw`. |

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o `.exe` não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**. A soma SHA-256 de cada arquivo está em `SHA256SUMS.txt`.

## Correções e novidades

- **Trocar a pasta do recomp.** Em **Gravar no jogo**, o botão **Trocar a pasta do recomp** aceita a pasta do programa ou a pasta de dados dele. Se a pasta de dados foi movida (o recomp deixa um aviso apontando para o lugar novo), o programa também acha sozinho.
- **Idioma do console no recomp.** O recomp não aplica o idioma do `Dolphin.ini`: o jogo lê o idioma guardado na memória do console (`GC/SRAM.raw`). Ao gravar na versão europeia, o programa agora muda o idioma nos dois lugares. Sem isso, a tradução gravada no lugar do espanhol não aparecia.
